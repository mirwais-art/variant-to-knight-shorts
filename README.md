# VariantFPS → Knight Shorts

Automatic highlight worker for videos owned by the channel operator.

- Source: https://www.youtube.com/@VariantFPS/videos
- Destination: Knight (@real-knight)
- Cadence: one prepared Short every 72 hours
- Output: 1080x1920 MP4, approximately 20 seconds
- Selection: unused long-form videos, action-heavy moment detected from audio peaks

The generated clip is published as the `latest` GitHub Release asset. Uploading to YouTube is handled separately through the connected Knight publishing profile.

No files or workflows from the SardarWaliTeaStore repository are used or modified.
